# 像素侵入：系统保卫战

一款纯离线的HTML5 Canvas互动游戏

## 游戏简介

《像素侵入：系统保卫战》是一款以"像素侵蚀"为核心机制的塔防类点击游戏。玩家需要在规定时间内消灭不断出现的病毒像素，保护系统不被侵蚀。

## 核心特色

### 🎮 三大关卡
1. **文档保卫战** - 保护你的毕业论文不被病毒侵蚀
2. **桌面封锁线** - 小心伪装病毒，解锁围城模式
3. **蓝屏核心** - 最终决战，动态难度挑战

### ⚡ 核心机制
- **侵蚀与恢复**：病毒会"吞噬"背景，消除后恢复清晰
- **污染度系统**：达到60%触发降维打击，画面模糊化
- **连击系统**：5秒内连续击杀触发过载模式，分数翻倍
- **动态警报**：根据时间和病毒数量触发不同警报级别

### 🎁 道具系统
- **时空补丁** ⏰ - 增加15秒时间
- **绝对零度** ❄️ - 冻结所有病毒5秒
- **逻辑炸弹** 💣 - 清除屏幕上所有红色病毒

### 🎨 视觉效果
- 像素化侵蚀效果
- 故障艺术（Glitch）
- 屏幕震动
- 爆炸粒子
- 降维打击效果

## 如何运行

### 方法一：直接打开
双击 `index.html` 文件即可在浏览器中运行

### 方法二：本地服务器
```bash
# 使用Python
python -m http.server 8080

# 或使用Node.js
npx http-server
```
然后访问 http://localhost:8080

## 操作说明

### 移动端
- 点击病毒像素消灭它们
- 点击底部道具图标使用道具

### PC端
- 鼠标点击病毒像素
- 按空格键或ESC键暂停游戏

## 游戏技巧

1. **优先击杀快速病毒** - 它们停留时间短，分数高
2. **注意迷惑病毒** - 绿色和蓝色是伪装，点击会扣分
3. **保持连击** - 连续击杀触发过载模式，分数翻倍
4. **合理使用道具** - 在关键时刻使用道具扭转局势
5. **控制污染度** - 污染度超过60%会触发降维打击

## 开发者工具

在浏览器控制台中可以使用以下调试命令：

```javascript
// 添加道具
debug.addPowerup('timePatch', 3)  // 添加3个时空补丁
debug.addPowerup('freeze', 2)     // 添加2个绝对零度
debug.addPowerup('bomb', 1)       // 添加1个逻辑炸弹

// 设置分数
debug.setScore(1000)

// 设置时间
debug.setTime(60)

// 清除所有病毒
debug.clearViruses()

// 跳转到指定关卡
debug.jumpToLevel(0)  // 跳转到第一关
debug.jumpToLevel(1)  // 跳转到第二关
debug.jumpToLevel(2)  // 跳转到第三关

// 显示游戏状态
debug.showState()
```
